# 🤖 AI Chat Website



This is a simple AI-powered chat website built with Python and Flask.



The application allows users to send messages and receive AI-generated responses in real time.



## 🚀 Features

- AI chat using a local model (Ollama)

- Real-time communication

- Conversation history

- Simple and clean UI



## 🛠️ Technologies

- Python

- Flask

- Ollama

- HTML / CSS



## 🧠 What I Learned

- Building a web application with Flask

- Connecting frontend and backend

- Working with APIs and AI models

- Handling user input and responses



## 🧪 Development

This project was created as a learning project.



I used \*\*vibe coding (with ChatGPT assistance)\*\*, but I made sure to understand how the code works.



## ⚠️ Notes

- The app works locally (localhost)

- Requires Ollama installed

- `.env` is not included for security reasons
